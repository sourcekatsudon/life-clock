# 人生時計 - Life Clock

このアプリケーションは通常の時計ではなく、人間の人生を時計の針に対応させた「人生時計」を表示するWeb版アプリです。美しいデザインの時計で、あなたの人生の進み具合を視覴的に確認できます。

## 機能

### 基本機能
- 美しいアナログ時計表示
- 2つの表示モード切り替え：
  - **カレンダー式**: 長針=日月、短針=人生の進行、秒針=時刻
  - **単純式**: 寿命を24時間換算（長針=分、短針=時、秒針=秒）
- AM/PM表示（人生の前半=AM、後半=PM）
- リアルタイム更新

### デジタル表示
- 現在の日時と曜日
- 現在の年齢（年月日）
- 残り時間（年月日）
- 残り週数
- 人生の進捗（パーセンテージとプログレスバー）

### カスタマイズ機能
- 5つのテーマから選択可能：
  - かっこいい（デフォルト）
  - レトロ
  - シンプル
  - 明るい
  - ゆるい
- 生年月日の設定
- 想定寿命の設定（50-120年）
- 表示モードの選択

## 使い方

### 基本的な使用方法

1. Webブラウザで `index.html` を開きます
2. 右上の設定ボタン（⚙️）をクリック
3. 生年月日と想定寿命を設定
4. お好みのテーマと表示モードを選択
5. 「保存」ボタンをクリック

### 表示モードについて

#### カレンダー式
- **長針**: 月の進行（1年で1周）
- **短針**: 人生の進行（寿命で2周）
- **秒針**: 1日の時刻（24時間で1周）

#### 単純式
- **長針**: 分（60分で1周）
- **短針**: 時間（寿命の半分で1周）
- **秒針**: 秒（60秒で1周）
- 寿命全体を24時間に換算して表示

### 針の説明
時計の下部に表示される説明文で、各針の意味を確認できます：
- カレンダー式: 「長針=日月 短針=人生 秒針=時刻」
- 単純式: 「長針=分 短針=時 秒針=秒」

## カスタマイズ

### テーマの特徴
- **かっこいい**: ダークで洗練されたデザイン
- **レトロ**: 温かみのあるブラウン系デザイン
- **シンプル**: 清潔で分かりやすいホワイト系デザイン
- **明るい**: 鮮やかで元気なカラフルデザイン
- **ゆるい**: 優しくパステル調のデザイン

### レスポンシブデザイン
- デスクトップ、タブレット、スマートフォンに対応
- 画面サイズに応じて自動レイアウト調整
